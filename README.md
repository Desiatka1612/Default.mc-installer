# Default.mc Installer

Универсальный установщик лаунчера Default.mc.

## Скачать

- [Default.mc_Setup.exe](./Default.mc_Setup.exe)
- Прямая ссылка на последнюю версию: https://github.com/Desiatka1612/Default.mc-installer/releases/latest/download/Default.mc_Setup.exe

## Что внутри

- Установщик не привязан к версии лаунчера: при установке скачивается актуальный launcher.zip из релизов.
- Java не устанавливается: лаунчер сам подберёт и при необходимости скачает нужную версию Java.
- Можно выбрать папку установки; создаётся ярлык в меню «Пуск».
- Если лаунчер уже установлен, установщик предлагает обновить или удалить его.
